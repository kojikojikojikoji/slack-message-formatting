# Slack mrkdwn and Block Kit: detailed guide

Supplement to SKILL.md. Details, edge cases and the list of block types live here.

## 1. Syntax by route (full table)

| Syntax | Native mrkdwn (MCP server with `text/plain`, curl, webhook) | CommonMark (Slack connector in Claude, MCP server default) |
|---|---|---|
| Bold | `*bold*` | `**bold**` |
| Italic | `_italic_` | `_italic_` or `*italic*` |
| Strikethrough | `~strike~` | `~~strike~~` |
| Inline code | `` `code` `` | `` `code` `` |
| Code block | ` ``` ` | ` ``` ` |
| Link | `<url|text>` | `[text](url)` |
| List | `•` or `-` by hand | `-` |

> To remember it: native uses one symbol (`*`, `~`), CommonMark uses two (`**`, `~~`). Italic is `_` in native too.

## 2. Edge cases and pitfalls

- No nested emphasis: `*bold _italic_*` does not render as expected. Use only one.
- Symbols inside a word are unreliable: `*bold*` works with a space or line edge on both sides. Something like `ver*sion*` may not.
- To stop link previews, add `unfurl_links=false` and `unfurl_media=false` to the message arguments.
- Writing `@name` does not notify anyone. It is plain text. Use `<@U012AB3CD>` to notify.
- Channel IDs survive renames: `<#C012AB3CD>` follows a renamed channel. Add `|name` to fix the displayed name.
- Line breaks: in JSON, use `\n`. With curl `--data-urlencode "text=..."`, you can put real line breaks in the value. curl encodes them.
- Emoji: `:tada:` is a shortcode. Unknown names show as plain text. Custom emoji depend on the workspace.
- Escaping order: replace `&` with `&amp;` first, then `<` with `&lt;` and `>` with `&gt;`. The other order escapes twice.
- `>>>` quotes: everything after it, to the end of the message, is quoted. You cannot stop it partway. Use `>` for a single line.

## 3. Date format `<!date^ts^tokens|fallback>`

- `ts`: Unix seconds.
- Tokens: `{date_num}` (2014-02-18), `{date}` (February 18th, 2014), `{date_short}` (Feb 18, 2014), `{date_long}` (Tuesday, February 18th, 2014), `{time}` (9:39 AM), `{time_secs}` (9:39:36 AM). Relative: `{date_pretty}`, `{date_short_pretty}`, `{date_long_pretty}` (these use "today" and "yesterday").
- To make the date a link, add `^https://...` after the tokens.
- `|fallback` is required (for old clients and notifications).
- Example: `<!date^1392734382^{date_short_pretty} at {time}|Feb 18, 2014 at 9:39 AM PST>`

## 4. Block Kit block types (most used first)

| type | Use | Main fields |
|---|---|---|
| `section` | Body text. One `text`, or two-column `fields` (up to 10) | `text` (mrkdwn or plain), `fields[]`, `accessory` |
| `header` | Large heading (plain_text only) | `text` |
| `divider` | Horizontal rule | none |
| `context` | Small supporting text (several elements, images allowed) | `elements[]` (mrkdwn or image) |
| `actions` | Buttons, selects and other interactive elements | `elements[]` (button, select, datepicker, ...) |
| `image` | Image | `image_url`, `alt_text`, `title` |
| `rich_text` | Rich text (lists generated by programs, etc.) | `elements[]` |

- Text objects: `{"type":"mrkdwn","text":"..."}` or `{"type":"plain_text","text":"...","emoji":true}`.
- In place of a table: put `*Label*\nvalue` items in `section.fields` to get a two-column label and value layout.
- Up to 50 blocks per message. Always include top-level `text`. It is the notification preview and the fallback.
- Interactive elements such as buttons need interactivity set up in your Slack app. For one-off notifications, display only is enough.

## 5. Looking up channel IDs

```bash
# SLACK_TOKEN is a bot (xoxb) or user (xoxp) token, loaded from your own .env
curl -s -X POST https://slack.com/api/conversations.list \
  -H "Authorization: Bearer ${SLACK_TOKEN}" \
  --data-urlencode "types=public_channel,private_channel" --data-urlencode "limit=200" \
  | python3 -c "import sys,json;[print(c['id'],c['name']) for c in json.load(sys.stdin)['channels']]"
```

Get user IDs for mentions from `users.list`. For a DM, call `conversations.open` and use `channel.id`.

## 6. Common conversions (CommonMark to native mrkdwn)

| From | To |
|---|---|
| `**important**` | `*important*` |
| `~~removed~~` | `~removed~` |
| `[docs](https://example.com)` | `<https://example.com|docs>` |
| `# Heading` | `*Heading*` (bold as a substitute) or a Block Kit `header` |
| Table `| a | b |` | Block Kit `section.fields` |
| `- item` | `• item` (if you want a consistent look) |
